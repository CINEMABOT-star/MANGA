Collega il tuo GitHub

Per pubblicare usa una chiave dedicata al repository CINEMABOT-star/MANGA. L’anteprima funziona anche senza accesso.

  1. Apri la creazione della chiave su GitHub ↗
  2. In Repository access scegli Only select repositories e seleziona MANGA.
  3. Controlla Contents: Read and write, premi Generate token e incolla la chiave qui.

La chiave resta solo in memoria in questa pagina. Dopo una ricarica dovrai inserirla di nuovo.

Il TXT e le pagine saranno aggiunti al tuo repository pubblico.
